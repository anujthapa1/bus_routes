🚌 Nepal Local Bus & Fare Guide
An open-source web platform designed to map local bus routes in Nepal, provide real-time fare calculations, and document legal discount rights for citizens.


🌟 Features
Route Mapper: Interactive maps showing major local bus routes (Kathmandu Valley, Pokhara, etc.).
Fare Calculator: Calculate costs based on distance using the latest government-mandated "scientific fare" rates.
Discount Navigator: A dedicated section explaining legal 45% (student) and 50% (senior/disability) discounts with links to official legislative acts.
Legal Support: A quick-guide on what to do and who to call (103/1148) if discounts are denied.
Crowdsourced Updates: Users can report new routes or changes in stops.


⚖️ Legal Framework



This project references the following official documents to ensure accuracy:
The Senior Citizens Act, 2063 (2006)
The Act Relating to Rights of Persons with Disabilities, 2074 (2017)
DoTM (Department of Transport Management) Fare Directives
